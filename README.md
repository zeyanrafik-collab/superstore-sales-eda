# superstore-sales-eda
Exploratory Data Analysis (EDA) of Superstore sales data using Python, Pandas, NumPy, Matplotlib, and Seaborn. Analyzes sales, profit, product categories, regional performance, customer segments, discounts, and time-based trends to uncover business insights and support data-driven decision-making.
# Superstore Sales Analysis and Business Insights

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Superstore sales dataset using Python. The goal is to understand sales and profitability patterns, evaluate product and regional performance, examine discount impacts, and identify business trends through statistical analysis and visualizations.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Key Analysis Areas
- Data inspection and quality checks
- Data cleaning and preparation
- Statistical analysis
- Sales and profit distribution
- Discount versus profit analysis
- Product, customer, and regional performance
- Time-based sales trends
- Data visualization and business insights

## Project Objective
To strengthen practical data analytics skills by transforming raw sales data into meaningful insights that can support business decision-making.

## Files
- `Superstore_Sales_EDA.ipynb` — Jupyter Notebook containing the analysis.
- `Sample - Superstore.csv` — Source dataset, which should be included in the repository if its usage and sharing terms permit.

## Skills Demonstrated
Python, data cleaning, exploratory data analysis, statistical analysis, data visualization, and business insight generation.
